# CDL-云签速印（LabelFlash）

CDL 出品的扫码打标签工具，支持 Windows 和 macOS。用扫码枪扫描二维码或条码，软件按识别规则拆出字段，立即按模板生成标签的预览（默认 60×40mm，模板可以换成其他标签或快递面单尺寸），并打到装着这种纸的本机打印机上。样衣标签（`编码-颜色-尺码`，例如 `CL5640-TK-图片色-XL`）、纯数字订单号、多行「名称：值」内容开箱即用，其他格式可以自己配规则。

## 支持的系统

| | Windows 10/11（x64） | macOS |
|---|---|---|
| 扫码、识别规则、预览、模板、打印记录、语音、打印结果通知、密钥 | ✅ | ✅ |
| 打印到本机打印机 | ✅ | ✅（家用打印机已实测，热敏标签机待验证） |
| 驱动纸张检测、打开打印机设置 | ✅ | ✅ |
| 打印机离线 / 缺纸 / 卡纸检测与提醒 | ✅ | 暂不支持（不影响打印） |
| 安装包与自动更新 | ✅ | pkg 安装包；暂不自动更新，新版本到发布页下载 |

## 功能

- **扫码即打**：扫码后自动预览、自动打印；也可以切换成手动模式，预览确认后按 F2 打印。
- **工作台 + 配置中心**：
  - 工作台只放扫码时用得到的东西：扫码框、备注、自动打印，标签预览（顶部工具条是这一张用的模板，规则指定时标「规则指定」），右侧打印记录。
  - 模板、常用备注、识别规则、查找表、密钥、打印结果通知、语音播报、通用设置和关于都在配置中心：点标题栏「配置」或按 Ctrl+,（macOS ⌘,）打开，铺满窗口，Esc 返回。
  - 配置中心里永远不打印：扫码内容会填进识别规则的「试一试」或模板的「预览内容」，其他页面会提醒「正在配置，没有打印」。离开有未保存修改的编辑器前会先确认。
- **识别规则**（配置中心「识别规则」页）：
  - 四种规则：分隔符拆分、多行键值、整段匹配（例如纯数字订单号）、正则（在隔离环境里执行，带超时）。
  - 内置横杠三段、纯数字订单号、多行键值、原样打印四条规则；从上到下逐条匹配，可以调整顺序、停用。
  - 规则可以绑定模板：例如订单号用大二维码的模板，其他用当前模板。
  - 还可以按字段换模板：同一条规则里，某个字段包含或等于某个值时换成另一套模板（字段可以是加工步骤补出来的）。例如订单号经 HTTP 查询拿到快递公司，顺丰用顺丰面单、德邦用德邦面单、其他用平台标准面单；纸张和打印机跟着模板走，扫码枪和手机扫码都一样。
  - 「试一试」实时显示命中哪条规则、识别出哪些字段；规则可以单条或全部导出成文件分享给别的厂家，导入时逐条校验。
- **加工步骤**：识别之后生成新字段，给模板、备注和二维码用。
  - 文本拼接（例如把订单号拼成网址放进二维码）、正则替换（例如去掉前缀）。
  - 查找表：从 CSV 导入的本机表格（支持中文 Excel 默认的 GBK 编码），例如按编码查货架号；导入后可以查看前 20 行核对。
  - HTTP 查询：调用接口取数据，结果短时缓存；接口令牌存成密钥，用系统加密保存在本机，不随规则导出。查询失败可以选择照常打印或不打印并提示。导入的规则里有 HTTP 查询时先停用，并列出它会访问的地址。
  - 图中文字识别（货架号）：手机扫码时顺带把整张标签拍下来（按二维码摆正，横着、斜着拍都行），电脑用自带的文字识别（本地运行，不联网）读出上面的字，按正则取出货架号这类字段（例如 `A-1-2-3`、`B-12-3-10`），和其他字段一样用在模板里。可以设一个优先查找的位置（例如二维码下方），货架号换了位置照样找得到。认不出时默认不打印，手机上提示重扫或手动输入。扫码枪没有图，这一步跳过。识别速度分「极速」（默认）和「精准」两档，在「通用」里切换，模型都装在安装包里。目前只有 Windows 版带文字识别。
- **多行扫码**：二维码里有换行时，扫码枪会连续发出回车；软件按回车后的停顿（默认 80 毫秒，可调）判断是码里的换行还是扫完了。
- **防重复打印**：同一张标签在设定时间内只打印一次，默认 3 秒，主要用来挡住扫码枪连按。每次拦截都会显示、播报并记入打印记录。时间可以在配置中心「通用」页按秒调整，填 0 表示不拦截。重启软件后这个时间窗口依然有效。需要再打一张时，可以用"强制补打"。
- **打印模板**：
  - 内置 6 套通用标签模板（列出识别到的全部字段：样衣码就是编码、颜色、尺码，读到货架号时再多一行「货架号」，字段再多也不会把它挤掉）和 5 套快递面单（平台标准一联 / 二联给中通、圆通、申通、韵达、极兔，顺丰 100×180 和 100×150，德邦 100×180）。
  - 快递面单按毫米分行分格排版：格子永远拼满、线永远对齐，长地址先缩小字号再折行，放不下会在预览上提示；运单号印成 Code128 条码。面单的字段由订单系统经本机接口发来，或者扫订单号后由加工步骤（HTTP 查询）补出来（运单号要先向快递公司取好；电商平台电子面单取的号只能用平台自己的打印组件打，本程序不打）。复制后可以逐格修改。
  - 自由设计模板（吊牌、价签、商品条码）：在设计器里把文字、条码（Code128、EAN-13、UPC、Code39、ITF-14 等常用码制，另有 Data Matrix、PDF417 等）、二维码、图片（自动转黑白）、线、矩形、表格摆到标签上。画布显示的就是打印出来的样子；支持对齐、等距、吸附参考线、撤销重做、复制粘贴、方向键微调；底部列出打印前检查（例如条码位数不对、元素靠近纸边），可以先「打印一张试试」。在配置中心「模板」页点「新建自由设计模板」，或复制内置的吊牌示例。
  - 模板库：在配置中心「模板」页点「从模板库新建」，按分类（服装吊牌、价签、商品条码、鞋盒标、食品标签、珠宝 / 小商品、仓储）和纸张（30×20 到 100×150）挑一个，缩略图就是打出来的样子；点「用这个模板」复制成自己的模板，在设计器里改。设计器先用示例数据预览，可以马上「打印一张试试」。模板库的字段名（品名、编码、颜色、尺码、价格、商品码、生产日期、保质期、货架号……）和内置识别规则、批量打印的列名一致：Excel 表头用同样的名字，批量打印自动对上。
  - 配置中心「模板」页点选即可预览（用最近一次扫码的内容，也可以自己输入），编辑时表单和预览并排；字段名输入框会列出规则里出现过的字段名供选择。
  - 可以复制成自定义模板后自由调整：纸张尺寸（常用标签和快递面单预设，也可以自定义宽高）和指定的打印机；显示全部字段还是指定字段；字段横向（名称：值）或垂直（名称在上）排列；分隔符；二维码的位置、尺寸、容错等级和内容（完整内容、某个字段或带变量的文本）；备注文字。
  - 排版按打印机点阵优化：二维码每个模块取整数个打印点（按打印机驱动报告的分辨率，读不到按 203dpi），打出来边缘清晰；内容太长时自动降低容错，仍然扫不了就不印二维码并提示。文字取放得下的最大字号，订单号宁可缩小一点也不从中间断开。
  - 备注可以放在二维码旁的空白处或底部，支持 `{字段名}`、`{完整内容}`、`{规则}`、`{日期}`、`{时间}` 变量。
  - 扫码框旁的「备注」下拉框可以一键切换常用备注，常用备注在配置中心「常用备注」页管理。
- **手机扫码**：扫码枪不在手边时，用手机摄像头扫码，标签从这台电脑的打印机出来。
  - 点标题栏「手机扫码」，屏幕上出现一个二维码；用手机相机或微信扫它，打开扫码页，点「开始扫码」后对准标签，扫到就打。最多 5 部手机同时用，任务在电脑上排队，一张一张打；每部手机只看到自己的任务和排队位置。
  - 打印和扫码枪完全一样：识别规则、加工步骤、模板、防重复都照常生效，打印记录的来源记为「手机」。
  - 手机和电脑经中转服务通信：电脑只在点了「手机扫码」后才连接，结束或 30 分钟没有扫码就断开；二维码 10 分钟内没人打开就失效。内容端到端加密，中转服务看不到扫码内容。
  - 电脑上随时能看到加入了哪些手机，可以移除（移除后自动暂停新手机加入，需要时再允许）。
  - 中转地址在配置中心「通用」页设置。官方安装包默认用 yterm.cn 上的中转服务，也可以换成自己部署的（见 `relay/README.md`）。电脑要能直接访问中转地址的 443 端口：程序不走系统代理。
  - 手机网络不稳时不会丢、也不会重复打：断线期间扫的先存在手机上，连上后自动补发。
  - 规则里有「图中文字识别」时，手机随扫码带上整张标签的图（几十 KB），电脑读出货架号补进这一张；认不出时手机卡片上可以直接输入。
- **打印结果通知**：每次打印的结果以 JSON 发给最多 5 个地址（ERP、仓库系统、群机器人），带 HMAC-SHA256 签名。通知先存进本机队列、后台发送，断网自动重试（最长 24 小时），不影响打印；配置中心「打印结果通知」页可以发送测试、查看发送记录。
- **批量打印**：点标题栏「批量打印」（或把 .xlsx / .csv 拖进窗口），一页里自上而下设置：
  - 选模板（标签、面单、自由设计都行）；导入 Excel（.xlsx）或 CSV（支持中文 Excel 默认的 GBK 编码），或粘贴从 Excel 复制的表格，或不用数据、只按序号打几张。第一行是列名，最多 1 万行。.xls（97-2003）请先另存为 .xlsx 或 CSV。
  - 模板用到的每个字段按列名自动对上，对不上的标红，可以手动选一列或填固定值；序号 `{序号}` 可设前缀、起始、步长、位数（补零）、后缀，也可以取表里的一列；每行固定几份，或取「份数」列。
  - 左边是数据（可勾选要打的行、搜索），右边是当前行打出来的真实样子；缺字段、条码印不了的行标黄，汇总在顶部。
  - 按表格顺序一张一张打，可暂停、继续、取消；缺纸、没分配打印机时自动暂停，处理好后点继续接着打那一张；失败的行可以单独重打。不受防重复打印的时间窗口影响。
  - 每张一条打印记录（来源「批量」，带批次号、行号），打印记录里点「这一批」只看这一批，可以整批重打失败的。
  - Excel 文件在单独的子进程里读取（限时、限内存），坏文件不会影响程序本身。
- **本机接口**：别的网页系统、客户端软件把「模板 + 字段」交给本程序打印，或者只排版取回 PDF（接入说明见 `docs/local-api.md`）。
  - HTTP 接口，遵循 Google API 设计规范，附 OpenAPI 3.1 描述；一次最多提交 1000 张，逐张查询状态，出纸顺序和提交顺序一致。
  - 本机的网页第一次调用时，程序顶部出现询问并弹出系统通知，点「允许」后按网站记住，撤销之前一直有效；客户端软件、服务器程序用程序密钥（在配置中心「本机接口」页生成，只显示一次）。
  - 默认也对局域网开放（局域网里只认程序密钥），可以关掉。Windows 防火墙还没放行本程序时，局域网先不开，在「本机接口」页加上防火墙规则后自动开放。
  - 端口一般是 17631，程序记住用成功的端口，下次还用它；被别的程序占了才换（依次试 17631–17640），换了会提示。
  - 只有 HTTP，局域网里传输是明文，只在可信的局域网里使用。
  - 本机接口提交的每一张都完整保存字段（面单上可能有收件人信息），只存在这台电脑上：打印记录按保留条数删除，给调用方查进度的任务记录保留 7 天；打印记录可以按原样重打。
- **打印记录**：
  - 可以回看任意一条记录的预览，也可以重打。
  - 记录按环形方式保留，默认最多 10 万条，超出后自动删除最早的记录。
  - 支持按扫码内容全文搜索。
- **打印机**：一台电脑可以接几台打印机，每台装一种纸。在配置中心的「打印机」页按纸张分配打印机（标题栏的打印机状态点一下就到）（例如 60×40 标签 → 标签机，100×180 面单 → 面单机），每一张自动打到装着对应纸张的那台；个别模板也可以指定打印机。某台打印机的驱动纸张正好是某种纸时，会建议分配给它。软件会检查每台打印机的驱动默认纸张是否和它负责的纸一致；Windows 上还会检测被分配到的打印机是否离线、缺纸或卡纸。从 1.0.x 升级时，原来选中的打印机自动分配给 60×40。
- **标签机指令**（TSPL / ZPL / EPL）：配置中心「打印机」页每台打印机有「标签机指令」，可以直接给热敏标签机发设置：
  - 指令集默认「自动」：驱动名里写着 TSPL、ZPL 或 EPL 时自动认出；认不出时请手动选，不确定就选「不发指令」，打印照常经驱动。
  - 能设浓度、速度、纸张（宽、高、间隙纸或黑标纸）、打印方向、出纸方式（撕纸 / 剥离，EPL 不设）；每一项都可以「不改」。点「保存并发送」时发一次，之后打印不再重复发。
  - 动作：纸张校准、走一张纸、打印自检页、恢复出厂设置（要确认两次）。
  - 指令是单向的：程序只知道已经发出去，打印机有没有照做要看出纸。经驱动打印时，驱动「打印首选项」里的同名设置可能盖过这里的设置。
  - Windows 经系统的后台打印服务直接发送（RAW）；macOS 用系统自带的 `lp`。驱动不接受直接发送时会说明怎么办。
- **窗口**：Windows 上是无边框窗口，按钮由软件自绘；macOS 上保留系统红绿灯。关闭窗口时最小化到托盘（macOS 是菜单栏），并支持开机自启。
- **语音播报**：每种结果播一句固定的话，共 21 句，用词和状态栏一致，例如「已发送打印」「重复扫码，已拦截」「打印机缺纸」「正在配置，没有打印」。播报按「故障 > 提醒 > 确认」分级，故障提示不会被随后的确认打断。配置中心「语音播报」页可以调整音色和语速，并逐句试听。音频缓存在本机，播放无延迟。
- **打印机异常提醒**（Windows）：离线、缺纸、卡纸时弹出系统通知；同一台打印机的同一种问题 30 分钟内不重复，每天最多 2 次；一台缺纸不会压住另一台的缺纸通知。
- **自动更新**（Windows）：从 GitHub Releases 后台下载新版本，只下载和本机版本不同的部分（差分下载）；标题栏提示后重启即可更新，也可以在配置中心「通用」页手动检查。

## 安装、更新与卸载（Windows）

- **安装**：从 [GitHub Releases](https://github.com/HeiSir2014/LabelFlash/releases) 下载 `CDL-LabelFlash-Setup-<版本>.exe`，双击运行，点「立即安装」。
  - 安装包还没有代码签名，第一次运行时 Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」。
  - 按当前用户安装，安装本身不需要管理员权限，默认装到 `%LOCALAPPDATA%\Programs\CDL-LabelFlash`，也可以点「更改」换位置。
  - 装完、启动程序之前会弹一次管理员确认，加一条防火墙规则，让局域网里的电脑能连本机接口（只放行本程序，所有网络类型都生效）。点「否」也照常装完，本机接口先只接受这台电脑上的调用，之后可以在配置中心「本机接口」页再加。卸载时删掉本程序的这条规则。
  - 装完自动启动程序，并默认开机自启（可以在配置中心「通用」页关掉）。
- **更新**：程序启动 15 秒后检查一次，之后每 4 小时检查一次，发现新版本就在后台下载。
  - 下载完成后，标题栏出现「新版本 x 已就绪 · 重启更新」，点两次确认，程序重启并装好新版本。
  - 一直不点也没关系：下次退出程序时会在后台静默安装，下次打开就是新版本。
- **卸载**：在 Windows「设置 → 应用」里卸载。安装目录、快捷方式和开机自启项都会删掉，`%LOCALAPPDATA%\CDL-LabelFlash` 里的数据保留，重装后接着用。

## 安装、更新与卸载（macOS）

- **安装**：从 [GitHub Releases](https://github.com/HeiSir2014/LabelFlash/releases) 下载 `CDL-LabelFlash-<版本>.pkg`，双击运行，按提示输入管理员密码，装进「应用程序」。Apple 芯片和 Intel 的 Mac 用同一个安装包。
  - 安装包还没有 Apple 开发者签名和公证，第一次双击时 macOS 会提示「无法验证开发者」：点「完成」，到「系统设置 → 隐私与安全性」底部点「仍要打开」，再运行一次。装好的程序可以直接打开。
- **更新**：macOS 版暂不自动更新（「关于」里会提示）。新版本发布后，下载新的 pkg 覆盖安装即可，数据保留；安装前先退出正在运行的程序。
- **卸载**：退出程序，把「应用程序」里的「CDL-云签速印」拖到废纸篓。`~/Library/Application Support/CDL-LabelFlash/` 里的数据保留，重装后接着用。

## 数据与日志

所有数据都保存在数据目录里：Windows 是 `%LOCALAPPDATA%\CDL-LabelFlash\`，macOS 是 `~/Library/Application Support/CDL-LabelFlash/`。

| 路径 | 内容 |
|---|---|
| `labelflash.db` | SQLite 数据库（Electron 内置 `node:sqlite`），包含设置、自定义模板、自定义识别规则、查找表、加密的密钥、通知发送队列和打印记录 |
| `logs\labelflash-YYYY-MM-DD.log` | 运行日志，每天一个文件（纯文本、UTF-8，时间带时区），保留最近 14 天；同一天超过 5MB 时滚动为 `.1.log`、`.2.log`。遇到问题时，把出问题那天的文件发给维护人员 |
| `voice-cache\` | 语音播报的 mp3 缓存，可随时删除，下次会重新生成 |

Windows 上另外还有两个目录：

- `%LOCALAPPDATA%\Programs\CDL-LabelFlash\`：程序本身，卸载时删除。
- `%LOCALAPPDATA%\cdl-labelflash-updater\`：自动更新的缓存，存着本机安装包的副本（差分下载时作为底）和已下载、待安装的新版本。

## 扫码枪设置

扫码枪需要能输出中文（二维码里有"图片色"之类的中文）。

- **Windows**：按扫码枪说明书扫描"中文输出 / Windows Unicode"设置码（扫码枪用 Alt+小键盘码输出中文，一般要打开小键盘的 NumLock，以说明书为准）。输入法不用切到英文：
  - 扫码框平时是「扫码模式」，关掉了输入法，中文模式下扫码也不会被输入法截走。
  - 用鼠标点进扫码框是「手动编辑模式」，可以用输入法打中文、在中间修改，回车提交；按 Esc、点别处或 10 秒不操作回到扫码模式。手动编辑模式下扫码，程序会按按键拼回扫码内容，拼不回来时会提醒。
- **macOS**：Windows 的「Alt + 小键盘」中文输出在 macOS 上不可用。按说明书选 macOS 对应的中文输出方式，并把输入法切到英文（ABC）。

扫码枪的结束符设为回车（默认即是）。二维码里的换行和制表符会以回车、Tab 发出，软件能区分；如果多行内容被拆成了几次扫码，在配置中心「通用」页把「多行扫码等待」调大一点。

## 开发

需要 [Bun](https://bun.sh) 1.4 或更高版本。Windows 和 macOS 都可以开发和运行；`dist:win` 只能在 Windows 上跑，`dist:mac` 只能在 macOS 上跑。

```bash
bun install
bun run dev        # 启动开发版
bun run check      # lint + 类型检查 + 单元测试
bun run test:e2e   # 构建后用 Playwright 启动 Electron 跑端到端测试
# 视觉验收：按设计文档 §8 截图并自动检查，结果在 test-results/visual-acceptance/
bun run build && bunx playwright test --config e2e/visual/playwright.config.ts
bun run icons      # 修改 resources/*.svg 后重新生成图标
bun run relay:dev  # 本机启动手机扫码的中转服务（http://localhost:3180），在配置中心填这个地址
bun run test:relay-browser  # 用 Edge 的假摄像头跑一遍手机扫码页
bun run installer:skin  # 只生成安装界面的皮肤（调界面时用），输出到 dist/.installer/
bun run dist:win   # 在 Windows 上打安装包，输出到 dist/
bun run dist:mac   # 在 macOS 上打 pkg 安装包，输出到 dist/
```

开发和测试时，设置环境变量 `CDL_LABELFLASH_USER_DATA` 可以让程序使用单独的数据目录，不动本机真实数据。这个变量只对开发版生效，安装版忽略它。

- 编码约定、提交前必须通过的检查、各层的规则：见根目录和各目录下的 `CLAUDE.md`。
- 安装包的构建、运行方式和插件来源：见 `resources/installer/README.md`。

GitHub Actions：

- 推送到 `master` 或提交 PR：在 Windows 和 macOS 上执行检查和 E2E 测试，并在两个平台上打包、上传安装包产物。
- 推送 `v*` 标签：两个平台的检查都通过后，把 Windows 安装包、`latest.yml`、blockmap 和 macOS 的 pkg 发布到 GitHub Release；已安装的 Windows 客户端会自动更新。
- 安装包的默认中转地址来自仓库的 Actions 变量 `LABELFLASH_DEFAULT_RELAY_URL`（代码里不写域名）；自己构建时可以用环境变量 `CDL_LABELFLASH_DEFAULT_RELAY_URL` 指定，不设就没有默认值。

发布新版本：

1. 修改 `package.json` 里的 `version`，经 PR 合进 `master`。
2. 在 `master` 的提交上打同名标签，例如 `git tag v1.0.1 && git push --tags`。发布作业会先检查：标签所在的提交在 `master` 上；标签和 `package.json` 的版本一致（客户端按版本号比较、按文件名里的版本找旧版 blockmap 做差分下载）；设置了默认中转地址。任何一项不符合都不发布。

`latest` 分支始终指向最新发布的版本：发布作业公开 Release 之后自动把它快进到新标签。最新的安装包在 [Releases 的最新版](https://github.com/HeiSir2014/LabelFlash/releases/latest)。

CI 的构建号（每跑一次自增）写进 Windows 文件版本和 macOS 的 CFBundleVersion，「关于」里显示为「v1.0.2（构建 123）」，报问题时能对上是哪一次构建；版本号本身不带它。

## 目录结构

```
src/core       业务层（纯 TypeScript，不依赖 Electron）：识别规则与加工步骤（scan/）、查找表（lookup/）、打印结果通知（notify/）、模板与排版（templates/）、防重门限、打印队列、PrintService
src/shared     主进程与界面共用：IPC 契约、设置、常量
src/main       Electron 主进程：app:// 协议、安全加固、SQLite 存储、正则沙箱与 HTTP 查询（scan/）、查找表导入（lookup/）、通知队列与签名（notify/）、密钥加密（secrets/）、打印适配器与二维码排布、打印机状态与异常通知、驱动纸张检测、语音缓存、IPC、窗口、托盘、日志、自动更新
src/preload    contextBridge
src/renderer   界面（React，MVVM：lib + view-models + components）
scripts/       构建脚本：bundle 自包含检查、图标生成、安装包（installer/：皮肤生成与两段构建）
resources/     应用图标和托盘图标（见 resources/README.md）、安装包资源（installer/）
e2e/           Playwright 端到端测试
relay/         手机扫码：云端中转服务（Bun）和手机扫码页，单独部署，不进安装包
docs/          设计文档、实施计划、路线图、Windows 验收记录
```
