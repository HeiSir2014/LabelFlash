# 局域网共享（IPP）

打开配置中心「局域网共享」后，这台电脑的每种「分配了打印机的纸张」就是局域网里的一台共享打印机（例如「60×40 标签 @ 前台」）。别的电脑不装驱动就能添加它，从任何程序打印：内容按这张纸缩放、转黑白后由这台电脑的热敏标签机打出来，每张都记进打印记录（来源「局域网共享」）。

共享默认关着：打开开关之前，程序不监听任何网络端口，也不在局域网里广播。

## 怎么添加

- **Windows 10 / 11**：设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 添加设备。列表里出现「60×40 标签 @ 前台」就直接添加；没出现就点「我需要的打印机不在列表中」→「按名称选择共享打印机」，填共享页上的 `http://` 地址（例如 `http://192.168.1.10:8631/printers/60x40`），驱动选「Microsoft IPP Class Driver」。
- **macOS**：系统设置 → 打印机与扫描仪 → 添加打印机，在列表里选「60×40 标签 @ 前台」，「使用」保持系统自动选的免驱打印（IPP Everywhere）。
- **iOS**：打印时在「打印机」里直接选它（系统自带的打印）。
- 新电脑第一次打印时，这台电脑顶部会问「允许 / 拒绝」并弹出系统通知；2 分钟没人点就作废，对方的任务显示中止。决定会被记住（按电脑的 IPv4 地址），在共享页可以撤销。

## 要知道的

- 只接受和这台电脑同一网段的电脑：对方的地址要落在这台电脑某块真实网卡（不算虚拟机、WSL、VPN 的虚拟网卡）的子网里。同一公司别的网段、经路由器过来的、VPN 分到的地址都连不上，一连上就断开，一个字节都不读。传输是明文 HTTP。
- 设了「共享密码」后别的电脑要输入它（用户名随便填）：打印、取消、查任务都要，只有查打印机本身（添加时）不要。每台电脑只看得到、只能取消自己交的任务，这是按地址分的：同一个 NAT（例如一台路由器、一个虚拟机网络）后面的几台电脑地址相同，互相看得到、能取消。连续输错 5 次之后，每错一次这台电脑要等 10 秒。密码在局域网里能被抓包看到：它挡住随手添加，不防有心人。程序只存密码的摘要（scrypt），忘了就重设。
- 「允许 / 拒绝」认的是电脑的 IPv4 地址，不是人：同一网段里谁拿到这个地址（换了电脑、地址重新分配、有人改成这个地址）就沿用这个决定。对方报的用户名、任务名是它自己填的，谁都能冒充，界面和打印记录里写作「自称用户」，看不见的格式字符（双向文字控制、零宽字符等）会被去掉。要更稳就设共享密码，并在路由器上给常用电脑固定地址。
- 端口默认 8631，被占用时自动换（共享页会说换成了哪个、被谁占着）；换了端口，按地址添加过的电脑要重新添加，自动发现添加的不受影响。
- Windows 安装版第一次打开共享时要点「添加防火墙规则」（管理员确认）：放行本程序的 TCP 连接，并加一条只放行同一网段（LocalSubnet）的 UDP 5353（自动发现）。安装包只加 TCP 那条（和本机接口共用），UDP 那条只在打开共享后由这个按钮加。没放行时共享先不监听。
- 收的格式：PDF、JPEG、PNG、PWG 光栅、URF 光栅。按文件内容认格式，不信对方声明的。PDF 和图片只在隔离的隐藏窗口里打开。文档最大 50MB、200 页；图片一边最多 14400 像素、最多 5000 万像素（先看文件头，太大的不解码）。
- 页面和纸差不多大（±3mm）的整页打；A4 上的一张面单、截图、照片会先去掉四周空白再放到纸上。照片用抖动，其余按阈值转黑白。多份按整份依次打（1、2、1、2）。
- 没被允许的电脑交来的任务另算名额：一共最多 2 个、每台电脑 1 个，文档加起来最多 50MB；它们占不满已允许电脑的名额。
- 共享还有已允许、没打完的任务时，退出程序会先问；「重启更新」会被拒绝；关在托盘里也不静默更新。还在等确认的任务不挡这些（退出、更新后它们中止）。

## 真机验证清单

每一项写进 `docs/windows-acceptance.md`（Windows）或 `docs/roadmap.md` 的 macOS 进度（macOS），记下系统版本、结果和程序日志里 `[ipp] job … format …` 那一行（看对方实际发来的格式）。

### 一致性（在 macOS 或装了 CUPS 的 Linux 上）

- [ ] `ipptool -tv ipp://<地址>:8631/printers/60x40 get-printer-attributes.test`、`ipp-2.0.test`：全部 PASS；没过的记下属性名。
- [ ] `ipptool -tv -f <一个 60×40 的 PDF> ipp://<地址>:8631/printers/60x40 print-job.test`：任务完成，出纸。

### Windows 客户端（Windows 11 24H2、Windows 10 22H2 各一台）

- [ ] 「添加设备」的自动搜索里出现「60×40 标签 @ 电脑名」，添加后驱动是「Microsoft IPP Class Driver」。
- [ ] 按地址添加（`http://…`）成功；打印测试页出纸。
- [ ] 记事本、Edge 里的 PDF、文字处理软件各打一张：出纸正确；日志里记下格式（预期 `image/pwg-raster`，也可能是 `application/pdf`）。
- [ ] 文字处理软件打 2 份：出 2 张、按份排序（旧的类驱动可能丢掉份数：记下实际结果）。
- [ ] 打印对话框的纸张列表只有这一种纸，名字可读。
- [ ] 打开「Windows 受保护的打印模式」（24H2）后仍能添加、打印。
- [ ] 设了共享密码：Windows 弹出凭据框，输入后能打；输错被拒。（如果 Windows 对 http:// 上的基本认证不弹框，记下来：文档里改成「Windows 上建议不设密码，只靠电脑询问」。）
- [ ] 标签机缺纸时打一张：Windows 的打印队列显示错误；放好纸后对方重发。
- [ ] 第一次打印：本机顶部出现询问和系统通知；点「拒绝」后对方任务显示错误；在共享页撤销后再打，重新询问。`job-held-for-authorization` 在 Windows 打印队列里怎么显示，记下来。

### macOS 客户端（macOS 15 一台）

- [ ] 「打印机与扫描仪」自动列出，「使用」是免驱打印；预览里打 PDF 出纸；日志里的格式（预期 `application/pdf` 或 `image/urf`）。
- [ ] 设了共享密码：macOS 要求输入并存进钥匙串。
- [ ] iOS 的「照片」「文件」打印能找到并打出（照片是抖动）。

### 这台电脑是 macOS（共享的一端）

- [ ] 开共享后别的 Mac、Windows 能自动发现（和系统的 mDNSResponder 共用 5353）；端口 8631 可用。
- [ ] pkg 安装版：系统防火墙不弹框（安装时已放行本程序）。

### 自动发现（真实局域网）

- [ ] 一台有 Hyper-V / WSL / VPN 虚拟网卡的 Windows 电脑开共享：广播里的地址只有真实网卡的；另一台电脑解析到的地址能连上。
- [ ] 局域网里另一台设备已经用了同名实例时，本程序改名为「… (2)」。

### Windows 安装包

- [ ] 新装：安装时的防火墙确认点「是」后，`Get-NetFirewallRule -DisplayName 'CDL-LabelFlash local API' | Get-NetFirewallPortFilter` 只有 TCP 一条。
- [ ] 打开共享、在共享页点「添加防火墙规则」后：多了 UDP 5353 一条，`Get-NetFirewallAddressFilter` 显示它的 RemoteAddress 是 LocalSubnet。
- [ ] 共享开着时在「本机接口」页点「添加防火墙规则」：UDP 那条仍在。
- [ ] 从上一个版本覆盖安装：TCP 规则在；本机接口照常对局域网开放。
- [ ] 卸载：本程序的规则都删掉。
- [ ] 另一个网段的电脑（经路由器）连共享端口：连接被断开。
