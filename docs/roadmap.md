# CDL-云签速印 路线图

依据：对一款同类标签打印管理软件（下称「参考产品」）做的功能盘点，结合样衣间「扫一打一」的场景逐项评级。原始盘点材料不放进仓库。

## 参考产品要点（只记对我们有意义的部分）

- **定位**：热敏标签机、面单机的打印机管理工具，主要用户是电商卖家，以及打吊牌、价签的小商家。
- **与我们同构的流程**：它的移动端「扫商品码 → 自动填价签模板 → 打印」与我们的核心流程一致，说明这类需求有市场验证。
- **我们的差异化**：扫码枪专用流程、防重门限、语音确认播报、本地全文检索的打印记录。
- **安全反例（不照搬）**：
  - 远程页面开启 `nodeIntegration`，关闭 `webSecurity`。
  - 本地服务端口不做鉴权。
  - SQL 靠字符串拼接。

## 状态

| 功能 | 评级 | 状态 |
|---|---|---|
| 打印机列表与状态检测 | 必须 | ✅ Phase 1 |
| 扫码 → 解析 → 填模板 → 静默打印 | 必须 | ✅ Phase 1 |
| 单实例 | 必须 | ✅ Phase 1 |
| 打印机异常通知（离线、缺纸、卡纸；同类 30 分钟冷却、每天最多 2 次；点击回到主窗口） | 必须 | ✅ Phase 1 |
| 打印测试页 | 建议 | ✅ Phase 1 |
| 语音确认播报（我方特有，本地缓存） | — | ✅ Phase 1 |
| 驱动纸张检测：读取驱动默认纸张和分辨率（`Win32_PrinterConfiguration`），不是 60×40 时提示，并提供按钮打开打印首选项 | 必须 | 待确认 |
| 状态语义修正：只有驱动明确报告问题才判定不能打印，队列为空时的"就绪"视为未知 | 必须 | ✅ 已写入规格 |
| 打印任务跟踪：发出任务后用 `Get-PrintJob` 跟踪，出现错误或停留超时就提示"可能缺纸或开盖" | 建议 | 待确认 |
| USB 在位检测：按 USB 设备 ID 检查标签机是否还连着，补上"断开后仍报告就绪"的缺口；换 USB 口导致离线时给出指引 | 建议 | 待确认 |
| 自动设置驱动纸张：调用 winspool 建 60×40 表单、设为默认、回读校验，失败回滚（需要新增原生调用依赖，且要确认是否需要管理员权限） | 建议 | 待确认 |
| 二维码按打印点对齐：生成 1-bit 二维码图片，每个模块取整数个打印点，文字保持矢量 | 建议 | 待确认，需要先在真机上评估 |
| RAW 指令直连（TSPL）：可选模式，尺寸、浓度、速度完全由程序控制，并能读取打印机状态；中文全部画成位图 | 建议（P2） | 待确认，需要先确认客户机型的指令集 |
| 标签学习、开机空走一张、浓度速度设置的操作指引 | 建议 | 待确认 |
| 离线原因指引：按缺纸、离线等给出处理步骤 | 建议 | 待确认 |
| 系统打印队列：查看、暂停、清空（当前用户权限即可） | 建议 | 待确认 |
| 一键修复：清队列、打测试页、确认出纸（重启 spooler 需要管理员权限，不做） | 建议 | 待确认 |
| 清除缓存并重启（自助排障） | 建议 | 待确认 |
| 款号库：用「编码」补充款名、面料、季节等字段 | 建议 | 待确认 |
