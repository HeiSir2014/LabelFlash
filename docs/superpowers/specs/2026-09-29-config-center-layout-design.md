# 工作台 + 配置中心：界面信息架构重构

- 日期：2026-09-29
- 版本：随 1.0.1 一起发布
- 前置：[通用识别规则与通用模板](2026-09-28-generic-scan-rules-design.md)、[Phase 1 设计](2026-09-28-label-flash-design.md) §9 界面
- **取代**：Phase 1 设计 §9 的侧栏结构、悬停预览和扫码框回焦规则（在配置中心里的部分），通用识别规则设计 §6 的页面位置（「第 5 个标签页」「设置页」）。界面功能本身按 §3.1 逐项保留或迁移。
- 验收方式：逐项视觉验收（§8），每一项都要截图核对并由需求方确认

## 1. 背景与问题

现在的界面是「左边扫码 + 预览，右边 380px 侧栏 5 个标签页」。1.0.1 加入识别规则、加工步骤、查找表、密钥、打印结果通知之后，这个布局有三个问题：

- **两类任务挤在一条侧栏**：
  - 操作：扫码、看预览、选打印机、查记录，频率高，操作员一直在用。
  - 配置：编辑模板和规则、导入表格、设置通知，频率低，通常由管理员做。
  - 两者共用一条 380px 的侧栏。
- **编辑器太窄**：最小窗口（1024×680）下，规则编辑器要滚动好几屏，「试一试」被压在最底下，改一项要来回滚动才能看到效果。
- **空间浪费**：编辑规则时，左边 60% 宽度的标签预览和规则毫无关系；右侧「打印机」页平时大半是空的。

## 2. 目标

- 操作员的工作台只保留高频操作，扫码台的专注度不下降。
- 配置有足够的空间：表单和效果（预览、试一试）左右并排，改一项立刻看到结果。
- 最小窗口 1024×680 下所有页面不出现横向滚动条，文字不被意外截断。
- 配置期间不会误打印；扫码枪在配置页里也有用处（直接拿真码试规则、试模板）。

**不做**：新开系统窗口、多窗口；拖拽排序（保留上移下移按钮）；深色主题。

## 3. 信息架构

```
工作台（默认）
├─ 扫码栏：扫码框 · 备注 · 自动打印
├─ 预览区：预览工具条（模板切换 · 命中规则）· 标签预览 · 状态条
└─ 右侧栏：打印机 | 打印记录

配置中心（标题栏「配置」按钮 / Ctrl+, 或 ⌘, 进入，铺满标题栏以下区域）
├─ 标签
│  ├─ 模板
│  └─ 常用备注
├─ 识别
│  ├─ 识别规则
│  ├─ 查找表
│  └─ 密钥
├─ 集成
│  └─ 打印结果通知
└─ 系统
   ├─ 语音播报
   ├─ 通用（防重复、多行扫码等待、打印记录保留、开机自启、软件更新、日志）
   └─ 关于
```

### 3.1 现有功能的去向（一项都不能丢）

| 现有功能 | 去向 |
|---|---|
| 标题栏：Logo、产品名、版本、淘宝店铺、打印机胶囊、窗口按钮、「新版本已就绪 · 重启更新」 | 保留；新增「配置」按钮（§4.5） |
| 扫码栏：扫码框、备注下拉框、自动打印 | 保留；备注下拉框的「管理常用备注…」改为打开配置中心的「常用备注」页 |
| 预览：软尺、缩放、出纸动画、示例内容、二维码放不下的提示、状态条、打印 / F2、强制补打 | 保留 |
| 预览角标「规则 · 模板」 | 移到预览工具条（§4.3） |
| 预览角标「模板编辑中」、悬停 1 秒预览模板 | 删除：模板编辑和选中预览都在配置中心的模板页里完成 |
| 打印机页：搜索、刷新、当前标记、测试页、驱动纸张提示和打开打印首选项、已保存打印机不在系统里的提示 | 工作台右侧栏「打印机」 |
| 打印记录页：全文搜索、加载更多、回看预览、重打、总数 / 上限、多行只显示首行 | 工作台右侧栏「打印记录」；搜索框占位文字改为「按扫码内容搜索」 |
| 模板：使用、复制、编辑、删除、编辑器 | 配置中心「模板」；「使用」同时在预览工具条的下拉框里 |
| 常用备注：添加、删除、变量说明、上限 20 条 | 配置中心「常用备注」 |
| 设置：防重复、多行扫码等待、打印记录保留（调小时删除旧记录的二次确认）、开机自启 | 配置中心「通用」 |
| 设置：语音开关、音色、语速、逐句试听 | 配置中心「语音播报」 |
| 设置：打印结果通知 | 配置中心「打印结果通知」 |
| 关于：更新状态文字、检查更新、打开日志目录 | 配置中心「通用」的「软件更新」「日志」两行 |
| 关于：产品名、版本、出品方、店铺链接和二维码、数据目录 | 配置中心「关于」 |
| 识别规则全部功能、查找表、密钥 | 配置中心对应页面 |

- **视图状态**只有两种：`workbench`，或 `config/<页面>`（可带编辑对象，例如 `config/rules/edit/<id>`）。
- **不开新窗口**：同一个窗口里的覆盖层。新窗口会带来状态同步、托盘、焦点、任务栏图标等一系列问题，收益为零。
- **记住位置**：再次打开配置中心时回到上次的页面（本次运行内记住，不持久化）。

## 4. 工作台

### 4.1 布局

与现在相同：`grid-template-columns: minmax(0, 1fr) var(--side-width)`，侧栏宽 380px。

### 4.2 扫码栏

- 控件不变：扫码框、备注下拉框、自动打印开关。扫码框的输入区至少 240px。
  - 放不下时（窗口宽度约 1140px 以下，例如 1024），备注和自动打印整体换到扫码框下方第二行，扫码框占满整行。
  - 用 `flex-wrap` 按内容自动换行，不设断点：备注选项的文字长短不同，换行时机随之变化。
- **扫码框与输入法**（1.0.3 起）：扫码枪是逐键「打字」的键盘，中文输入法在中文模式下会截走按键（字母进拼写窗口、数字选候选词、回车只用来上屏）。
  - Windows 上默认是**扫码模式**：扫码框是透明的密码框（Chromium 只在密码框里关输入法），盖在显示文字、光标和选区的文字层上。扫码枪输出中文用的 Alt+小键盘码由 Windows 键盘层换成字，不经过输入法，不受影响。
  - 鼠标点进扫码框进入**手动编辑模式**：换成普通输入框，能用输入法打中文、有真实光标和选区；虚线边框，边框上方显示「手动输入 · 回车提交 · Esc 返回扫码」。回车提交、Esc、焦点离开、10 秒没有操作都回到扫码模式。
  - 输入法开着时扫码（手动编辑模式、macOS）：按物理按键（code + Shift + Alt 码）拼回扫码枪发出的内容，丢掉输入法组出来的字；拼不出来的不提交，扫码条下方提醒。
  - 码里的换行、Tab 在扫码框里显示成 ⏎、⇥；粘贴多行内容保留换行。
- **对齐修正**（1.0.1，当时扫码框是 `textarea`；现在的文字层同样固定高 32px、行高 32px）：在 150% 缩放下，占位文字比「扫码」标签低约 8px（Windows 实测）。
  - 原因：textarea 不像 input 那样把单行文字垂直居中；占位文字字号（15px）比输入文字（22px）小，行框贴着 textarea 顶部，所以显得偏高。
  - 修正方法：textarea 固定高度 32px、`line-height: 32px`、上下内边距 0，占位文字也用 `line-height: 32px`，由外层 flex `align-items: center` 居中。
  - 验收：在 100%、150%、200% 三种缩放下，「扫码」标签、占位文字、输入文字的**中线**对齐（字号不同，基线本来就不在同一高度），误差不超过 1px。

### 4.3 预览区新增工具条

预览区顶部新增一条高 44px 的工具条（取代预览右上角的「规则 · 模板」角标）：

| 位置 | 内容 |
|---|---|
| 左 | 「当前模板」标签 + 下拉框（宽度随最长的模板名，最宽 220px）：切换当前模板，等同于原模板页的「使用」；没有绑定模板的规则都用它 |
| 右 | 这一张实际用到的规则和模板：「规则：横杠三段（编码-颜色-尺码） · 模板：通用（二维码在左）」；模板由规则指定时，模板名后加「（规则指定）」 |

- 右侧文字过长时单行省略，完整内容放在悬停提示里。
  - 分两段省略：先省略「规则：…」，模板那一段（决定打出来的样子）尽量完整。
  - 模板段不收缩，最宽为整行减去 5 个字宽；1280 宽度下样衣码的整段模板文字（含「（规则指定）」）完整可见。
- 没有扫码时右侧显示「示例内容 · 模板：当前模板名」。
- **正在查询**：扫码后预览请求超过 200ms 还没返回（通常是加工步骤里的 HTTP 查询），状态条显示「正在查询…」（`pending` 色调），预览保持上一张直到结果返回。
- 预览上原来的角标都去掉：「规则 · 模板」进工具条；「示例 · 模板名」改为工具条右侧的「示例内容」；「模板编辑中」「悬停预览」随模板编辑移到配置中心，工作台不再出现。
- 只保留二维码放不下的提示，仍在预览下方（`label-badge`）。
- 工具条背景 `--color-paper`，底边 1px `--color-rule`，左右内边距 `--space-4`。

### 4.4 右侧栏

只保留两个标签页，各占一半宽度：**打印机**、**打印记录**。内容与现在相同，打印记录搜索框的占位文字改为「按扫码内容搜索」。

### 4.5 标题栏

- 右侧从左到右：「新版本已就绪 · 重启更新」胶囊（有更新时）、「配置」按钮、打印机状态胶囊、窗口按钮（Windows）。
- 「配置」按钮：齿轮图标 + 文字「配置」，与打印机胶囊同一种胶囊样式（高 28px、全圆角、描边、透明底），与左右元素间距 `--space-2`。更新胶囊、「配置」按钮、打印机胶囊三者同高。
- 配置中心打开时按钮变为按下状态（`--color-tape` 底、`--color-ink` 字），`aria-pressed="true"`。文字始终是「配置」：切换按钮的名称不随状态变（否则读屏念成「配置中，已按下」），宽度也不变，1024 宽时标题栏不跳动。
- 标题栏是墨色底，这里的焦点框改用 `--color-tape`，墨色的默认焦点框看不见。
- 悬停提示：「打开配置（Ctrl+,）」；macOS 显示「⌘,」。

## 5. 配置中心

### 5.1 框架

```
┌──────────────────────────────── 标题栏（40px，不被覆盖） ───────────────────────────────┐
├───────────────────────────────────────────────────────────────────────────────────────────┤
│ ← 返回工作台   │  识别规则                                    [配置中不打印]              │ ← 页头 56px
├────────────────┼──────────────────────────────────────────────────────────────────────────┤
│ 标签           │                                                                          │
│   模板         │                         页面内容（各自滚动）                               │
│   常用备注     │                                                                          │
│ 识别           │                                                                          │
│ ▌ 识别规则     │                                                                          │
│   查找表       │                                                                          │
│   密钥         │                                                                          │
│ 集成           │                                                                          │
│   打印结果通知 │                                                                          │
│ 系统           │                                                                          │
│   语音播报     │                                                                          │
│   通用         │                                                                          │
│   关于         │                                                                          │
└────────────────┴──────────────────────────────────────────────────────────────────────────┘
```

- **覆盖范围**：标题栏以下整个窗口（`inset: var(--title-bar-height) 0 0 0`），背景 `--color-housing`。
- **工作台**在配置中心打开期间设为 `inert`：不能获得焦点、读屏软件跳过，扫码框不会收到任何按键。
- **导航栏**：
  - 宽 184px（窗口宽 ≥ 1200px）或 160px（更窄时），背景 `--color-paper`，右边 1px `--color-rule`，自身可滚动。
  - 分组标题：12px、`--color-ink-soft`、上边距 `--space-4`、左内边距 `--space-4`。
  - 导航项：高 36px，左内边距 `--space-5`，14px；悬停背景 `--color-housing`；当前页背景 `--color-tape-wash` 加左侧 4px `--color-tape` 竖条（与「使用中」模板的标记一致），`aria-current="page"`。
- **页头**：高 56px，背景 `--color-paper`，底边 1px `--color-rule`：
  - 左：「← 返回工作台」按钮（`button--quiet`）。
  - 中：页面标题 18px 700。二级页面显示面包屑：「识别规则 / 编辑：下划线查货架」，第一段可点击返回列表。
  - 右：常驻提示胶囊「配置中不打印」（`--color-warning-wash` 底、`--color-ink` 字、12px）。
- **内容区**：内边距 `--space-5`，内容最大宽度 1200px（超宽屏不拉得过长），纵向滚动只发生在内容区内部。
- **进出动画**：打开时透明度 0→1、上移 8px→0，160ms；关闭相反；`prefers-reduced-motion` 时无动画。
  - 关闭时工作台**立即**恢复（取消 inert、焦点回扫码框、F2 可用），配置中心只是在上面淡出，淡出期间自身设为 inert：点「返回工作台」后马上扫码也不会丢。

### 5.2 页面的通用样式

- **页面说明**：标题下一行说明文字，13px、`--color-ink-soft`、最大宽度 720px。
- **卡片**：`--color-paper` 底、1px `--color-rule` 边、圆角 `--radius`、内边距 `--space-4`，卡片之间间距 `--space-4`。
- **表单行**：沿用 `form-row`，标签列在配置中心里加宽到 120px。
- **主操作按钮**：页面或编辑器右下角的操作条（高 64px、上边 1px `--color-rule`、`--color-paper` 底、固定在底部不随内容滚动）：左侧放校验失败原因，右侧依次是次要按钮、主按钮。

### 5.3 模板页

- **列表视图**：左右两栏。
  - 左 320px：模板列表（「内置」「自定义」两个分组标题），每行显示名称和「使用中」标签，行高至少 52px。选中行高亮（同导航当前项样式）。
  - 右（剩余宽度）：选中模板的大号实时预览（标签按宽度自适应缩放，最大 3 倍），上方是「预览内容」输入框（默认最近一次扫码内容，没有则用示例），下方是操作按钮：使用、复制、编辑、删除（删除要点两次确认）。
  - 取代原来的「悬停 1 秒预览」：点选即预览，不再依赖鼠标停留。
  - 预览套用工作台备注下拉框当前的选择，和打出来的一样。
- **编辑视图**：面包屑「模板 / 编辑：xxx」，左右两栏。
  - 左：编辑表单（`minmax(380px, 1fr)`，自身滚动），分区与现在相同：基本、二维码、字段、底部整行、备注。
  - 右：实时预览（`minmax(360px, 1fr)`，固定不滚动），上方同样有「预览内容」输入框。
  - 窗口宽度 < 1100px 时：预览移到表单上方，高度固定 220px，表单在下面滚动。
  - 「指定字段」的字段名和「二维码内容 · 某个字段」的字段名输入框带候选列表（`datalist`）：候选来自所有规则里出现过的字段名（分隔符字段、键值字段、整段字段、正则命名分组、加工步骤产出的字段），加上预览内容这次识别出的字段名；先列这次识别出的字段，再按规则列表的顺序列其余字段，去重。仍可输入候选之外的名字。
- **扫码**：焦点不在输入框时扫码，内容填进「预览内容」。

### 5.4 常用备注页

- 说明卡片：用途（工作台备注下拉框一键切换，只替换模板的备注文字，位置和字号仍按模板）和可用变量（`{完整内容}` `{规则}` `{日期}` `{时间}` 和 `{字段名}`）。
- 列表：每条一张卡片，多行照原样显示，右侧「删除」。
- 新增：多行输入框 + 「添加常用备注（n/20）」按钮；重复或为空时按钮不可用。
- 工作台备注下拉框的「管理常用备注…」打开这一页。

### 5.5 识别规则页

- **列表视图**：左右两栏。
  - 左（剩余宽度）：工具条（新建规则类型选择 + 新建、导入、导出全部自定义规则）+ 规则列表。每条规则一张卡片：
    - 第一行：启用勾选、名称、标签（内置规则显示「内置」，自定义规则显示类型）、「加工 N 步」标签。
    - 第二行：摘要（等宽字体、12px、单行省略，完整内容在悬停提示里）。
    - 第三行：「用的模板」下拉框（宽 240px）、上移、下移、复制、编辑、导出（只导出这一条）、删除（两次确认）。内置规则没有编辑和删除。
    - 停用的规则：名称和摘要变灰、加删除线。
  - 右 360px（固定，不随列表滚动）：「试一试」，按真实扫码的顺序识别。
- **编辑视图**：面包屑「识别规则 / 编辑：xxx」，左右两栏。
  - 左：规则表单 + 加工步骤（`minmax(420px, 1fr)`，自身滚动）。加工步骤一次展开一个。
  - 右 360px（固定）：「试一试」，只用正在编辑的草稿。
  - 底部操作条：校验失败原因 | 放弃修改 / 返回列表、保存规则。
  - 窗口宽度 < 1100px 时：「试一试」移到表单上方，折叠成一行输入框 + 一行结果摘要，点「展开」看完整结果。
- **扫码**：焦点不在输入框时扫码，内容填进「试一试」。

### 5.6 查找表、密钥

- **查找表**：卡片列表（名称、行数、列名、更新时间；替换、删除）+ 右上角「导入 CSV 表格」主按钮。选中一张表时在下方显示前 20 行预览（表格，表头固定，横向可滚动——表格本身允许横向滚动，页面不允许）。行预览需要主进程新增 IPC `lookup:rows`（表 id、最多 20 行）。
- **密钥**：说明卡片（怎么引用、加密存放、不随规则导出）+ 名称列表（每行显示 `{密钥:名称}` 引用和「复制引用」按钮）+ 新增表单（名称、内容、保存）。
  - 复制经 IPC `secrets:copy-reference`（参数是密钥名称）由主进程代写：名称按密钥名称规则校验，且必须是已保存的密钥，引用文字在主进程拼好再写进剪贴板。页面的网页权限仍然一律拒绝（安全底线），不为复制放开剪贴板权限；也不提供「写任意文字」的通用接口，页面被攻破也改不了操作员的剪贴板。

### 5.7 打印结果通知

- 上半部分：接口列表（卡片），每个接口一行：名称、地址、订阅的事件、启用开关、发送测试、编辑、删除。
- 编辑接口时在列表下方展开编辑卡片（不弹窗）。
  - 操作和模板、规则的编辑器一致：状态文字「有未保存的修改，保存后才会发送 / 还没有修改」，按钮「放弃修改 / 收起」和「保存接口」（没有修改或填得不完整时不可点）。
  - 保存失败时编辑卡片留着，草稿不丢。
  - 编辑中那一行的开关、编辑、删除停用：免得列表上的操作和草稿互相覆盖（例如删掉正在编辑的接口后，保存又把它加回来）。
  - 在编辑中点另一个接口的「编辑」或「添加接口」，同样走未保存确认。
- 下半部分：发送记录表格（时间、事件、接口、结果、状态码、尝试次数、下次重试、操作），表头固定，最多显示 100 条，每 10 秒自动刷新，右上角「刷新」。

### 5.8 语音播报、通用、关于

- **语音播报**：沿用现有的播报设置（开关、音色、语速、逐句试听，列出全部播报语）。
- **通用**：每项一行，右侧是控件，下方是说明：
  - 防重复打印（秒）、多行扫码等待（毫秒）。
  - 打印记录保留（条）：调到比现有记录数还少时，先显示确认条「会删除最早的 N 条记录，删除后无法恢复」——取消 / 删除旧记录（再点一次「确认删除」）。每次重新提交数值都先收起上一次的确认条，不会按旧的数值删除。
  - 开机自动启动。
  - 软件更新：更新状态文字 + 「检查更新」按钮（检查中不可点）。
  - 日志：「打开日志目录」。
- **关于**：产品名、版本、出品方、淘宝店铺链接和二维码、数据目录。

### 5.9 指向其他页面的文案

凡是提示去别的页面操作的文案，都做成跳转链接（走未保存确认）：

| 位置 | 文案 | 跳到 |

| 工作台状态条 · 没有匹配的识别规则 | 说明「在『配置 › 识别规则』里启用『原样打印』，或新建一条能识别这种内容的规则」，状态条右侧按钮「打开『识别规则』」 | 识别规则 |

## 6. 交互细节

### 6.1 进入与离开

| 操作 | 结果 |
|---|---|
| 点标题栏「配置」、按 Ctrl+,（macOS ⌘,） | 打开配置中心，回到上次的页面；焦点移到页面标题（`tabindex="-1"`） |
| 点「← 返回工作台」、再按一次「配置」、Ctrl+, | 回到工作台，焦点回到扫码框 |
| Esc | 返回上一级：编辑视图 → 列表视图 → 工作台 |
| 离开有未保存修改的编辑器：切换导航、点面包屑、点跳转链接、返回工作台、再按「配置」或 Ctrl+,、Esc | 弹出确认框：「有未保存的修改」— 继续编辑（默认焦点）/ 放弃修改 |

- 确认框是原生模态 `<dialog>`（`showModal`，`role="alertdialog"`），宽 400px：打开期间标题栏、工作台、配置中心都不可操作，Tab 走不出去。Enter 等于「继续编辑」，Esc 等于「继续编辑」。
- 焦点：
  - 打开、切换页面、进出编辑视图时，焦点都移到页面标题（淡出中又打开同一页也一样）。
  - 确认框关闭后焦点回到打开前的位置；选「放弃修改」后换了页面时，焦点留在新页面的标题上，不被抢回导航。
- 下拉框、带候选列表的输入框（字段名）、输入法组字过程中的 Esc 不触发返回：那里的 Esc 用来收起下拉。按住不放产生的重复 Esc、Ctrl+, 不响应。
- 设置还没读到时，打开配置中心的操作不响应（没有内容可显示）。
- 编辑草稿按页面区分：离开任何一页都会关掉所有页面的草稿，异步建好的草稿（例如点「新建规则」后马上切走）不会出现在别的页面上。
- 删除一律两步确认：「删除」→「确认删除」（3 秒内再点一次），各页文字相同，常用备注也一样。
- 配置中心打开时，右下角的提示条抬到底部操作条上方，不盖住「保存」「使用」等按钮。

### 6.2 配置中心里的扫码

- 配置中心里**永远不打印**。
- **接收框**：焦点不在任何输入框时，扫码枪的第一个字符就把焦点切到页头里一个看不见的接收框（沿用工作台「第一个字符就切焦点」的机制），和扫码框用同一套逻辑按停顿拼成一次扫码（`view-models/use-scan-input.ts`），拼好后离开接收框。
  - 页面有测试框（识别规则的「试一试」、模板的「预览内容」）时：这次扫码**替换**测试框原有的内容，随即试一试 / 预览。不直接把焦点切进测试框，是因为那样新扫的码会接在旧内容后面，扫码枪发的 Tab 也会把焦点带走。
  - 其他页面：不写进任何设置；页头的「配置中不打印」胶囊闪烁两次（每次 300ms，`--color-warning`），并播报新增的一句「正在配置，没有打印」（提醒级）。语音共 20 句。
  - 接收框有 `aria-label`（「扫码内容（配置中心里不打印）」），不在 Tab 顺序里（`tabIndex=-1`）；确认框打开时不接收。
  - 接收框 1 秒没有新输入就清空并离开：那是误按的零散按键，不是扫码（扫码枪的字符间隔是几十毫秒，扫完后的停顿最长 500 毫秒）。不清的话，下一次扫码会接在残留内容后面，Tab 也会被当成扫码的分隔键移不走焦点。
- 焦点在输入框（文字、数字、密码、邮箱、网址、电话输入框和多行文本框，例如规则名称、密钥内容）时，按键照常输入该框——这是用户自己的操作。
- **下拉框不算输入框**：焦点停在下拉框上时扫码，照样进测试框或接收框。下拉框只会把字母当作跳选，扫码内容进去就丢了，还可能悄悄改掉选项（例如规则用的模板）。工作台同理。
- **工作台快捷键停用**：配置中心打开时 F2（打印）不响应（F2 监听在 `window` 上，`inert` 拦不住，要显式判断视图）。
- **自动回焦**：工作台的三条回焦规则（点按钮后 0.3 秒回焦、10 秒无操作回焦、窗口获焦回焦）在配置中心里全部停用——管理员正在填表，焦点留在他放的位置。只保留「焦点不在输入框时扫码，第一个字符就切到测试框或接收框」这一条。回到工作台后三条规则恢复。

### 6.3 数据同步

- 配置中心里的修改保存后立即生效：返回工作台时预览按新的规则和模板刷新一次（规则指定的模板、查找表、密钥改了都会影响当前这一张）。
- 工作台切换模板时，配置中心模板列表的「使用中」标记同步（共用同一个 view-model）。

## 7. 代码结构

- `App.tsx` 只负责组装：标题栏 + `Workbench` + `ConfigCenter`（打开时渲染）+ 通知条。
- 新增：
  - `view-models/use-app-view.ts`：视图状态（工作台 / 配置页）、返回上一级、未保存确认。
  - `view-models/use-config-center.ts`：配置中心的全部状态（视图、各页草稿、配置中心里的扫码、模板页预览，以及只在某一页用到的查找表内容、发送记录、店铺二维码、复制密钥引用），App 只把它接到界面上；页面组件不直接创建会访问主进程的 view-model。
  - `lib/editor-guard.ts`：按页面取编辑器、离开计划（先关草稿再执行），有测试。
  - `components/workbench/`：`Workbench`、`PreviewToolbar`、`WorkbenchSide`（打印机、打印记录两个标签）。
  - `components/config/`：`ConfigCenter`（框架、导航、页头）、`ConfirmDialog`，以及各页面 `TemplatesPage`、`NotePresetsPage`、`RulesPage`、`LookupTablesPage`、`SecretsPage`、`WebhooksPage`、`VoicePage`、`GeneralPage`、`AboutPage`。
  - `components/LabelPreview.tsx`：从 `PreviewStage` 抽出的纯标签预览（标尺 + iframe + 自适应缩放），工作台和模板页共用。
  - `lib/scan-routing.ts`：按当前视图决定扫码目标（工作台扫码框 / 规则页「试一试」/ 模板页「预览内容」/ 隐藏接收框）。
  - `lib/scan-focus.ts` 的 `isTypingField`（按键属于这个控件）和 `keepsFocus`（不自动拉回扫码框），工作台和配置中心共用，有测试。
- 复用：`TemplateEditor`、`FieldsAreaEditor`、`RuleEditor`、`RuleKindForm`、`StepForms`、`RuleTester`、`LookupTables`、`SecretList`、`WebhookSettings`、`VoiceSettingsSection` 只换容器，不改业务。
- 删除：`SidePanel` 的 5 标签结构、`TemplatePanel` 的悬停预览（`use-hover-preview`、`hover-intent` 里只剩扫码焦点用到的计时器部分）、`SettingsForm`（拆进各页面）。
- 新增纯逻辑：`lib/field-names.ts`（从规则和识别结果收集字段名候选，有测试）。
- 主进程新增两个 IPC，参数校验和现有通道一致：
  - `lookup:rows`：表 id → 前 `LOOKUP_PREVIEW_ROWS`（20）行；读出的单元格逐行校验是字符串数组。
  - `secrets:copy-reference`：密钥名称 → 把 `{密钥:名称}` 写进剪贴板（见 §5.6）。
- 预览结果 `LabelPreview` 增加 `isTemplateBound`：模板由命中的规则指定（即使恰好也是当前模板）。主进程的 `resolvePrintTemplate` 一次算出模板和这个标记。

### 8.3 自动检查（每张截图都跑）

- **无横向溢出**：页面内所有纵向滚动容器 `scrollWidth <= clientWidth`（明确允许横向滚动的表格除外）。
- **无意外截断**：可见文字元素 `scrollWidth <= clientWidth`，除非元素带有省略样式且设置了悬停提示（`title`）。
- **不重叠**：页头、导航、内容、底部操作条的矩形互不相交；固定区域（试一试、预览、操作条）不遮挡表单控件。
- **点击区域**：按钮、导航项、勾选框的可点击高度 ≥ 28px。
- **对比度**：正文与背景的对比度 ≥ 4.5:1，大字 ≥ 3:1。大字按 WCAG 的磅值换算成像素：≥ 18pt（24px），或 ≥ 14pt（约 18.67px）且字重 ≥ 700。
- **间距**：卡片、表单行的外边距和内边距只取 `--space-*` 的值（4 的倍数）。`margin: auto` 居中（例如确认框）算出来的是剩余空间，不是间距，不检查。
- **截断**：文字被任何一层会裁剪的容器（`overflow: hidden / clip`）挡住都算截断；能滚动的容器不算。省略号加悬停提示（`title`）是有意的省略，放行。
- **焦点**：配置中心打开时 `document.activeElement` 在配置中心内；工作台容器带 `inert`。

## 界面精简（2026-09-30）

逐页截图审视后去掉重复和多余的元素，原则是「一件事只在一处说」「只在有用的时候出现」。上文按当时的设计写，以这里为准：

| 原来 | 现在 | 为什么 |
|---|---|---|
| 打印机信息四处：标题栏胶囊、预览工具条「打印机：…」、右侧「打印机」页签、状态条出错提示 | 标题栏胶囊（有问题时变红，点一下打开「打印机」页）和状态条出错提示（「去指定打印机」）；打印机清单挪进配置中心「标签」分组的「打印机」页，放在白底卡片上 | 分配打印机是准备工作，不是每天扫码的事；清单占了工作台右侧一半 |
| 预览工具条：「当前模板」下拉框 + 「模板：…（规则指定）」说明，规则指定时两处对不上 | 只有一个「模板」下拉框，显示这一张实际用的模板；规则指定时锁住并标「规则指定」；右侧只写内容从哪来（「规则：…」或「示例内容」） | 同一件事说两遍，还互相矛盾 |
| 工作台右侧「打印机 \| 打印记录」两个页签 | 只有打印记录，没有页签头 | 打印机挪走后只剩一页 |
| 没扫码时状态条「等待扫码 · 扫码后自动预览并打印」 | 不说话（保留高度，第一张出结果时预览不跳） | 扫码框里写了怎么扫，「自动打印」开关就是模式 |
| 配置中心每页右上角常驻「配置中不打印」 | 只在没有测试框的页面扫了码之后出现并闪烁，回到工作台收起；播报照旧 | 常驻就是噪音，只在相关的时候提醒 |
| 模板列表每一行「60×40 标签 · 还没有打印机」 | 只在纸张不是默认、或模板自己指定了打印机时写纸张和实际会用的打印机 | 千篇一律的一行没有信息量 |
| 「集成」分组里单独的「手机扫码」页（中转地址 + 当前状态） | 中转地址并进「通用」；状态在标题栏的「手机扫码」按钮上 | 一个设置不值得一页，状态重复 |
| 「通用」里的软件更新和日志 | 挪到「关于」 | 通用只放扫码与打印的设置 |

标题栏的淘宝店铺和版本号保留（和「关于」重复，按需求方要求）。
