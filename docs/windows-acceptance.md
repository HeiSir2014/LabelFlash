# CDL-云签速印 Phase 1 — Windows 验收记录

本 PR 实现 Phase 1 计划（`docs/superpowers/plans/2026-09-28-label-flash-phase1-desktop.md`）的 Task 1–14（含 13A–13J）。内容包括：

- Windows 桌面客户端：扫码预览、防重复打印、模板、打印记录、打印机状态与驱动纸张检测、语音播报、异常通知、自动更新。
- 工程部分：`app://` 安全加固、E2E 测试、自绘 NSIS 安装包与 CI。

## 安装界面

- 界面插件是 nsNiuniuSkin，来源、版本、许可和 SHA-256 见 `resources/installer/plugins/NOTICE.md`。构建时校验哈希，不在构建过程中下载。
- 窗口是一个圆，圆外透明。插件本身不会按系统缩放放大界面，所以皮肤按 100%–300% 生成七份，安装程序按系统 DPI 选最接近的一份。
- 图形安装时，界面进程以静默子进程（`/skin-child /S`）执行真正的安装，按子进程退出码显示结果。
- electron-builder 遇到自定义脚本时不生成卸载程序，所以 `dist:win` 分两段构建：第一段用自带脚本取卸载程序，第二段打出发布的安装包（见 `scripts/installer/build-installer.ts`）。

## 与计划的差异

- 仓库默认分支是 `master`（远程已没有 `main`），CI 触发分支和 PR 目标改为 `master`；补上 CI 发布作业用到的 `release:win` 脚本。
- 在计划代码之上收紧了几处：
  - 解析器去掉字段两端空白，并拒绝零宽等不可见字符。
  - 防重门限拒绝非有限数的时间窗口；恢复记录时，未来时间钳到当前，超过 24 小时的跳过。
  - 打印队列在任务同步抛错时清掉计时器，并校验超时参数。
  - 打印记录在事务提交后才更新内存总数。
  - 驱动打印在中止时结束挂起的打印回调。
  - Edge 语音合成超时后接住被放弃的合成结果，不产生未处理的 rejection。
  - `app://` 路径拒绝解码后的反斜杠和 NUL。
- 计划完成后的加固：
  - 窗口按显示器工作区确定大小和最小尺寸，小屏、高缩放下不会跑出屏幕。
  - 保存窗口尺寸时扣掉 Windows 小数缩放下的创建误差：150% 缩放下每次启动窗口会大 2×3 像素，现已不再累积。
  - 输入框有右键「剪切 / 复制 / 粘贴 / 全选」，并关闭拼写检查。
  - GPU 进程崩溃时自动以软件渲染重启一次（已用 CDP 触发 GPU 崩溃实测）。
  - 渲染进程短时间内反复崩溃时不再无限重载。
  - IPC 处理失败时，在主进程日志里记下通道名和堆栈。
  - 拦截重定向，CSP 增加 `object-src` / `base-uri` / `form-action` 限制。
  - 日志按天命名为 `labelflash-<日期>.log`，纯文本，时间带时区，保留 14 天。
  - 安装依赖时即下载 Electron 二进制，CI 的 E2E 不再在测试里下载。
  - 覆盖安装和更新时不再删除开机自启项；只有真正卸载才删除。
- `src/main/storage/testing/temp-dir.ts` 只供测试使用：Bun on Windows 的 `node:sqlite` 在 `close()` 后仍占用数据库文件（[oven-sh/bun#40001](https://github.com/oven-sh/bun/issues/40001)），删除测试临时目录前需要强制 GC 并重试。产品运行在 Electron 自带的 `node:sqlite` 上，不受影响。

## 已知限制

- 安装包未做代码签名，首次运行会被 SmartScreen 拦一次。
- 安装界面插件用 UPX 压缩过，杀毒软件可能误报。上传送检会公开安装包，所以按决定等 1.0.1 正式包再送检，结果记在这里。
- 驱动纸张检测只提示，不自动修改驱动设置。
- 上表中标为「部分 / 待验收」的项目，需要在接好热敏标签机和扫码枪的 Windows 机器上完成后，再更新本记录。
