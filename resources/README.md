# CDL 云签速印图标

图标以界面的暖黄 `#F2C12E` 为底色，搭配绿色 `#2FAE63` 的弧形名称带和纸白 `#FBFBF8` 的大字；CDL 字标使用墨黑 `#18211E`，置于纸白圆角矩形中。完整图标以 512px 为基准，白色面板左右各留 64px 外边距，字标左右至少留 48px、上下至少留 55px 内边距；面板与绿色弧顶相隔 24px。底色为纯色，外框圆角之外透明。

- `icon.svg`：完整应用图标，含「云签速印」名称。文字均为路径，不依赖运行设备上的字体。
- `tray.svg`：标题栏和托盘使用的小尺寸版本，扩大 CDL 并省略中文，保留同一徽章轮廓。
- `icon.png`：512px 应用图标，由主窗口加载。
- `tray*.png`：16 / 20 / 24 / 32px 托盘图标，覆盖 100% / 125% / 150% / 200% 缩放。

修改 SVG 后运行 `bun run icons`，并一同提交生成的 PNG。标题栏直接引用 `tray.svg`，由 Vite 打包。

中文轮廓来自项目已有的得意黑，许可证位于 `src/renderer/src/assets/fonts/SmileySans-OFL.txt`。
